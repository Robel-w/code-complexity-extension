Start the backend with python app.py

How to use

  1. Start the Python backend server
  2. Navigate to any page with code blocks
  3. Hover over a code block and click ⚡ Analyze Complexity
  4. Or right-click selected code → Analyze Code Complexity

Severity Scale

Low (CC ≤ 5)
Medium (CC ≤ 10)
High (CC ≤ 20)
Very High (CC > 20)
